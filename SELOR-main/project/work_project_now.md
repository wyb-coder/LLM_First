# AMR-SELOR 下一阶段实施计划

> **背景**：基线实验已完成，Test Acc 63.69%，ROC-AUC 0.7058。核心问题已暴露：
>
> - 三元组解释重复（已修复推理逻辑）
> - 三元组数量爆炸（8 万+），大量无区分度
> - 未见三元组无法泛化

---

## 当前问题诊断

| 问题          | 现象               | 根因                       |
| ------------- | ------------------ | -------------------------- |
| CE 精度天花板 | ~75%               | 8 万三元组太稀疏，统计失效 |
| 测试集泛化差  | 大量样本 OOV       | 未见三元组无 embedding     |
| 解释质量低    | 功能性三元组被选中 | 无区分度过滤               |

---

## 实施计划

### Phase 1：情感区分度过滤（P0+）

**目标**：将三元组词表从 8 万 压缩到 ~10000，保留与标签显著相关的

| 任务                 | 说明                       | 落点                        |
| -------------------- | -------------------------- | --------------------------- |
| 卡方检验过滤         | 保留 p < 0.05 的三元组     | `build_triple_pool.py` 新增 |
| TF-IDF 加权          | 降低高频无区分度三元组权重 | 同上                        |
| 重新生成 true_matrix | 基于过滤后词表             | Stage 2 重跑                |
| 重新预训练 CE        | 更稠密的统计               | Stage 3 重跑                |

**预期收益**：CE 精度提升至 85%+，模型天花板打开

**细化与补充**：

- 过滤阈值：卡方显著性 p < 0.05；同时要求最小文档频率（如 df ≥ 5）以抑制偶发高卡方；可按正/负类分别取 top_k（默认 5000）。
- TF-IDF：使用子线性 TF 和 L2 归一化；对停用关系或超高频三元组施加额外降权（阈值可配）。
- 兼容性开关：`--filter_method none/chi2/tfidf`，默认 `chi2`，保留 `--top_k`；若需要验证旧流程，可设为 `none`。
- 产出与版本：过滤后词表与 true_matrix 按版本号落盘（示例 `result/triples/filtered.v1/triple_vocab.json`、`true_matrix.npz`），日志记录前后规模、保留率与每类 top_k 取值。
- 监控：运行时打印三元组保留数、被滤原因统计（高频、低频、低卡方），便于调参。

---

### Phase 2：三元组文本编码器（P1）

**目标**：让模型能处理未见三元组

| 任务                | 说明                               | 落点                           |
| ------------------- | ---------------------------------- | ------------------------------ |
| Triple Text Encoder | 用 DistilBERT 编码 `head rel tail` | 新增 `utils/triple_encoder.py` |
| 替换查表逻辑        | `embedding = encoder(triple_text)` | `amr_selor.py` 修改            |
| 推理时实时编码      | 无需预计算 embedding table         | `inference_amr_selor.py` 修改  |

**预期收益**：

- 测试集 OOV 问题解决
- 语义相近三元组自动聚类（如 `staff helpful` ≈ `waiter friendly`）

**细化与补充**：

- 模型参数：可配置 checkpoint（默认 `distilbert-base-uncased`）、最大长度（拼接 `head [SEP] rel [SEP] tail`）、池化方式（CLS/mean）。
- 性能：启用半精度/量化可选；训练时可缓存常见三元组 embedding，推理时用 LRU 缓存减少重复编码。
- 回退策略：对已存在的三元组仍可选择查表或编码，提供 `--triple_embedding_mode table/encoder/hybrid`；hybrid 模式优先查表，缺失时调用 encoder。
- 接口改动：`amr_selor.py` 接收 encoder 句柄与 tokenizer，移除对固定 `triple_emb_table` 的强依赖；`inference_amr_selor.py` 支持批量编码与并行度参数以加速推理。
- 产出管理：编码器配置与权重保存到 `result/triple_encoder/`，版本号与 Phase 1 过滤版本对齐便于复现实验。

---

### Phase 3：可选增强

| 优先级 | 任务                      | 触发条件              |
| ------ | ------------------------- | --------------------- |
| P1     | 指针网络选择器            | 基线选择质量不佳      |
| P1     | 组合式 Head/Rel/Tail 嵌入 | Text Encoder 成本过高 |
| P2     | 联合训练（解除 CE 冻结）  | 基线稳定后            |
| P2     | 复述鲁棒性评测            | 需验证解释一致性      |

**细化与补充（优先挑一到两个验证）**：

- 指针网络：替换或辅助手工打分选择器，重点验证对长文本与高冗余三元组的选取质量提升。
- 组合式嵌入：独立编码 Head/Rel/Tail 并组合，可与文本编码器做轻量对比，降低推理成本。
- 联合训练：解冻 CE 后，监控过拟合风险，必要时增加 dropout / weight decay；记录 CE 与主任务双指标曲线。
- 复述鲁棒性：对三元组文字进行同义改写，检查解释一致性；增加简单模板或回译扰动。

## SPRING 三元组抽取增强（适用于上游 AMR）

**目标**：减少功能性/噪声三元组，提升下游区分度。

- 关系筛选：建立关系白名单/黑名单（如过滤标点、对齐占位符），可配置文件驱动。
- 置信度与启发式：用分数或启发式（节点度、长度）过滤低置信边；裁剪过长尾的节点文本，统一大小写与空白。
- 去重与上限：同一文本出现的重复三元组去重；按文档限制三元组数量上限，优先保留高置信或高 TF-IDF 的。
- 统计与日志：输出每批三元组的均值/中位数长度、关系分布、过滤原因分布，便于回溯。
- 文件落点：过滤后的三元组存入版本化目录（示例 `result/spring_triples/filtered.v1/`），与 Stage 2 过滤版本对应。

## Phase 4：嵌入空间先验（研究方向）

> **核心思想**：从"统计计数"转向"Embedding 几何关系"来计算先验概率

### 动机

| 原 SELOR（统计先验） | 嵌入先验（新方向）       |
| -------------------- | ------------------------ | ------ | ----------------------------- |
| `P(pos               | triple) = count / total` | `P(pos | triple) = f(embed, centroid)` |
| 需要大量样本统计     | 只需嵌入向量的几何关系   |
| 无法处理未见三元组   | **可泛化到任意三元组**   |
| 受限于词表覆盖率     | 语义相似自动聚类         |

### 可能的实现路径

#### 路径 1：类别质心距离

```python
centroid_pos = mean(CLS of positive samples)
centroid_neg = mean(CLS of negative samples)

embed_t = TripleEncoder("head rel tail")
dist_pos = distance(embed_t, centroid_pos)
dist_neg = distance(embed_t, centroid_neg)

P(pos | t) = softmax(-dist_pos, -dist_neg)
```

#### 路径 2：投影到情感轴

```python
sentiment_axis = centroid_pos - centroid_neg

projection = dot(embed_t, sentiment_axis) / ||sentiment_axis||
P(pos | t) = sigmoid(projection)
```

#### 路径 3：对比学习先验

- 训练对比学习模型：正对 (triple, pos_sample)，负对 (triple, neg_sample)
- 推理时计算与类别原型的相似度

### 与 SELOR 输出的对应

| SELOR 输出           | 嵌入空间对应物      |
| -------------------- | ------------------- |
| `μ`（类别概率）      | 距离/投影 → softmax |
| `σ`（不确定性）      | 到最近质心的距离    |
| `coverage`（覆盖率） | 邻域内样本密度      |

### 创新点

1. **完全解决 OOV**：任何三元组都能编码并计算先验
2. **语义泛化**：相似三元组自动获得相似先验
3. **无需预训练 CE**：直接用几何关系，简化 pipeline
4. **可解释性保留**：仍然是"选择三元组 → 解释预测"

### 潜在挑战

| 挑战                 | 可能的解决方案               |
| -------------------- | ---------------------------- |
| 嵌入空间未必对齐情感 | 在情感数据上微调编码器       |
| 质心可能不准         | 使用多个原型（K-means 聚类） |
| 计算成本             | 缓存常见三元组嵌入           |

### 触发条件

- Phase 1-3 完成后，作为架构升级方向探索
- 适合作为后续论文的主要创新点

## 探讨前沿（暂不实施）

> 以下方向跳出 SELOR 框架限制，属于架构级创新，作为后续深入研究的备选。

---

### 前沿 1：端到端 AMR 编码器

**核心思想**：不再将 AMR 拆成三元组，直接编码整个 AMR 图结构。

```
当前：AMR 图 → 三元组列表 → 独立嵌入 → 选择
前沿：AMR 图 → 图编码器 → 统一表示 → 选择子图
```

| 方面       | 说明                                  |
| ---------- | ------------------------------------- |
| **输入**   | PENMAN 格式 AMR 或邻接矩阵            |
| **编码器** | Transformer 编码线性化 AMR / 图编码器 |
| **输出**   | 图级嵌入 + 节点级嵌入                 |
| **优势**   | 保留 AMR 全局结构信息                 |
| **挑战**   | AMR 结构复杂，序列化后很长            |

---

### 前沿 2：GNN on AMR（详细分析）

**核心思想**：用图神经网络直接在 AMR 图上学习节点/边表示。

#### 架构设计

```
AMR 图结构:
  节点: 概念（如 food, amazing, service）
  边:   关系（如 :ARG0, :mod, :manner）

GNN 层:
  h_v^(l+1) = σ( W · AGG({h_u^(l) : u ∈ N(v)}) + b )

其中 AGG 可以是:
  - GAT: 注意力加权邻居
  - RGCN: 按边类型分别聚合
  - GraphSAGE: 采样邻居聚合
```

#### 实现路径

| 步骤            | 实现细节                                               |
| --------------- | ------------------------------------------------------ |
| **1. 图构建**   | `penman.decode(amr_str)` → `torch_geometric.data.Data` |
| **2. 节点特征** | 概念文本 → BERT/Word2Vec 嵌入                          |
| **3. 边特征**   | 关系类型 → one-hot 或学习嵌入                          |
| **4. GNN 层**   | 2-3 层 RGCN（关系感知）                                |
| **5. 图池化**   | 全局平均池化 / 注意力池化                              |
| **6. 分类头**   | MLP → softmax                                          |

#### 可解释性保留

```python
# 节点重要性（注意力分数）
node_importance = attention_weights  # 来自 GAT 或额外注意力层

# 解释生成
top_k_nodes = argsort(node_importance)[-k:]
explanation = [node_concept[i] for i in top_k_nodes]
```

#### 与 SELOR 的对比

| 方面           | SELOR              | GNN on AMR    |
| -------------- | ------------------ | ------------- |
| **原子单元**   | 词/三元组          | AMR 节点/子图 |
| **结构信息**   | 丢失               | 保留          |
| **可解释形式** | 规则               | 关键节点/路径 |
| **训练方式**   | CE 预训练 + 选择器 | 端到端        |

#### 潜在库

- `torch_geometric`：PyTorch 图神经网络库
- `dgl`：Deep Graph Library
- `penman`：AMR 解析

### 前沿 3：放弃 CE 预训练

**核心思想**：不再预训练后件估计器 (CE)，让模型端到端学习三元组与标签的关系。

#### 当前流程

```
Stage 3: CE 预训练（学习 P(class | triples)）
Stage 4: 冻结 CE，训练选择器
```

#### 改进流程

```
单阶段: Selector + Classifier 联合训练
        ↓
  选择三元组 → 编码 → 分类 → 交叉熵损失
               ↑
         反向传播更新两者
```

#### 实现要点

| 要点         | 说明                           |
| ------------ | ------------------------------ |
| **选择器**   | GRU / Pointer Network / 注意力 |
| **编码器**   | 三元组嵌入求和 / Transformer   |
| **分类器**   | MLP → softmax                  |
| **损失**     | 分类交叉熵 + 可选稀疏正则      |
| **可解释性** | 选择器的选择概率作为解释       |

#### 优势与风险

| 优势          | 风险                     |
| ------------- | ------------------------ |
| 简化 pipeline | 可能过拟合（无先验约束） |
| 端到端优化    | 解释可能不稳定           |
| 无需统计先验  | 需要更多训练数据         |
